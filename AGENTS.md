# Repository Instructions

## Language

- Write all repository-authored content in English. This includes source identifiers, comments, docstrings, documentation, package metadata, CLI and UI copy, examples, tests, and developer-facing messages.
- Do not add Portuguese prose, prompts, aliases, fallback input tokens, or replaceable fixtures.
- Non-English text is allowed only when required by a locale-specific public contract or by a fixture that verifies Unicode, localization, transliteration, or encoding behavior.
- Describe any locale-specific exception in English, and translate non-English prose in every file you touch.
